Methodology. For every batter on each team's active roster vs the opposing probable starter, we pull career head-to-head splits from the official MLB Stats API (vsPlayerTotal hydrate). Rates are shrunk toward each batter's 2026+2025 season rates using a Beta-Binomial empirical-Bayes posterior with prior strength k=60 PA: p_post = (α + x) / (α + β + n) where α = season_rate · k, β = (1−season_rate) · k, and (x, n) are observed BvP successes/trials. Edges are p_post − season_rate; edge_1+ hit uses 1 − (1−p_h)4 for a typical 4-PA game. EDGE_SCORE is a z-weighted blend (40% hits / 30% HR / 20% OBP / 10% K-avoid) over today's qualified pool. Min-PA filter excludes BvP samples below 10 PA. Sources: MLB Stats API · scripts/scrape_bvp_today.py · scripts/rank_bvp_edges.py.
