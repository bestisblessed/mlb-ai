⏺ Three separate bugs were found and fixed across today's session:

  ---
  1. Bovada alt strikeout odds — regex broken (0 lines scraped for all pitchers)

  Bovada's frontend framework started injecting <!----> comment nodes inside
  their HTML, changing the structure from:
  <span class="bet-price"> -700 </span>
  to:
  <span class="bet-price"> -700 <!----></span>

  The regex expected the number to be immediately followed by </span>, so it
  matched nothing. Fixed in all 3 Bovada pitcher props scrapers. Also bumped the
   post-tab-click wait from 3–4s to 6s so Angular finishes rendering before
  scraping.

  ---
  2. BallparkPal pitcher names missing from game simulations CSV

  BallparkPal renamed their pitcher page URLs from Pitcher.php →
  Pitcher-Summary.php. The scraper looked for links with Pitcher.php in the
  href, found none, and silently skipped writing starter_away/starter_home to
  the CSV. Fixed the CSS selector in all 4 BallparkPal scraper files to match
  both URL patterns.

  ---
  3. Streamlit home page showing **Career BvP vs ** (blank pitcher names)

  Downstream consequence of bug #2. The home page reads
  starter_away/starter_home from the game simulations CSV to build headings like
   **Career BvP vs Williams** and to look up the correct BvP data file. Since
  those columns were empty, everything showed blank.

  Fixed in Home.py with a fallback: if the CSV columns are missing, read the
  pitcher name from the per-game proj_box_pitchers_*.csv files instead (those
  come from a different scraper and were unaffected). This also ensures old 2025
   data still works — it hits the CSV first and the fallback is never triggered.
